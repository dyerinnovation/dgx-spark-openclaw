# Udemy Courses Pipeline

Automated course creation pipeline for Dyer Innovation.

## Pipeline Stages
1. Topic research (weekly trending topics/search terms)
2. Content gathering and outline creation
3. Slide generation with OpenAI visuals
4. Script writing (Udacity lesson structure)
5. Audio production via ElevenLabs
6. Playwright-driven slide narration assembly
7. Review and approval via `#michael-approvals`
